# Marketing (Arki)

Site público de marketing. Next.js, porta 3001.

## Dev

Na **raiz do monorepo**:

```bash
bun run dev:marketing
```

Acesse http://localhost:3001.

## SEO e assets

Para compartilhamento em redes sociais e favicon, coloque em `public/`:

- **og.png** — imagem Open Graph / Twitter Card (recomendado 1200×630 px).
- **favicon.ico** — ícone da aba do navegador.

Veja `public/README.md` para detalhes.
