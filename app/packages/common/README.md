# `@workspace/common`

Utilitários compartilhados. Use os subpaths:

- **common/errors** — classes de erro (ValidationError, NotFoundError, etc.)
- **common/http** — HttpMethod, MediaTypeNames
- **common/guards** — Maybe, isDefined, isString
- **common/app** — APP_NAME, APP_DESCRIPTION
- **common/image** — resizeImage, decodeBase64Image
- **common/maybe** — tipo Maybe (ou use common/guards)
